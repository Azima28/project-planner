# Forward-Test Matrix

Choose scenarios that represent the actual archetype and capabilities; do not only test generic software templates.

| Scenario | Provable passing |
|---|---|
| Small landing page without sensitive data | Concise model; does not force database, API, or 14 documents |
| Backend/migration | Does not force UI flow; has data/rollback/test edges |
| Research programme | Research work items have question, evidence, method, decision exit |
| Partner has no API access | Receipt chooses mock/defer/investigate; no production claims |
| Payment/offline/inventory | Policy produces lifecycle, reconciliation/conflict, owner, failure test |
| User-facing multi-role or channel | Channel per role, service blueprint, accessibility/recovery, and usability test plan appear without forcing an application |
| Visual/UI or mockup requested | Tasks/states precede visuals; referenced local assets exist; no claims of "liked by many users" without testing |
| Sensitive/regulated/AI | Evidence, data boundary, human/legal owner, abuse/fallback outputs appear |
| Web fails/paywall/conflicting sources | Tool-failure/contradiction evidence, confidence lowered, fallback recorded |
| Multiple teams/legacy change | Ownership, impact edges, compatibility/migration/rollback artifacts appear |
| User changes priorities/provider | Change request + all impacted artifacts regenerated with new hashes |
| Local artifact/link missing or metadata stale | Validator reports missing asset/link, artifact ID/envelope mismatch, or stale receipt validation |
| Capability without artifact/edge | Validator reports missing policy candidate or `requires` edge even if model is still draft |
| Old output out of sync | Freeze `draft_invalid`; synchronization report finds plan→output and output→plan gaps |
| Secret or PII pasted | Value is not rewritten; only reference/status is stored |
| Pilot/production claim | Gate evidence, owner, monitoring, rollback, and access status valid; without them `not_ready` |

A scenario passes only if model, graph, report, and actual artifact files all state the same thing.
